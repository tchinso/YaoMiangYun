# Yao VPN

Windows 10/11 x64용 작은 VPN ON/OFF 앱입니다. 구독에서 VLESS, Hysteria2, AnyTLS 연결 정보만 읽고, 고정한 공식 sing-box 1.14.4 코어를 사용합니다. 기본 연결 방식은 **전체 시스템 TUN**이며, 기본 통신 모드는 **자동 판단**입니다. 관리자 권한 없는 앱 프록시도 선택할 수 있습니다.

## 사용

1. `artifacts/YaoVPN/YaoVPN.exe`를 실행합니다. 폴더 안의 `core`와 런타임 파일도 함께 유지하세요.
2. HTTPS 구독 주소를 넣고 **구독 불러오기 / 새로고침**을 누릅니다. 이 컴퓨터에 준비한 구독은 암호화된 로컬 캐시에서 자동으로 불러옵니다.
3. 사이트 규칙에서 통신 모드를 고릅니다. 기본값인 **자동 판단**은 연결마다 최초 10분간 전체 VPN을 사용한 뒤, 그동안 관찰한 도메인과 연결 시작 시 저장되어 있던 모든 규칙의 도메인만 VPN으로 보냅니다. 나머지는 일반 통신합니다. 기존 설정도 처음 한 번 자동 판단으로 전환하며 저장된 도메인은 유지합니다.
4. 서버와 연결 방식을 고르고 전원 버튼을 누릅니다. **앱 프록시**는 UAC 없이 시스템 프록시를 설정합니다. **전체 시스템 TUN**을 선택한 경우에만 관리자 권한을 요청합니다. 실제 VPN HTTPS 응답을 확인한 뒤 **ON**으로 표시합니다.
5. 다시 누르면 **OFF**로 돌아가며 이전 프록시/네트워크 설정을 복원합니다. 최소화하면 시스템 트레이로 이동하고 VPN 연결은 유지됩니다. 트레이 아이콘을 두 번 누르거나 우클릭 메뉴의 **열기**로 창을 복원합니다.
6. 창을 닫거나 트레이 메뉴의 **종료**를 누르면 VPN 종료와 네트워크 복원을 먼저 시도합니다. 정리에 실패하거나 45초 안에 완료되지 않아도 앱은 종료됩니다. 앱을 다시 실행해도 자동 연결하지 않습니다.

**공인 IP 변경 확인**은 연결 전과 현재의 Cloudflare HTTPS 응답을 비교합니다. 확인 사이트에 지정한 경로 규칙도 적용되므로 일반 통신으로 지정했다면 IP가 그대로인 것이 정상입니다. HTTP 웹페이지의 표시만으로 VPN 동작을 판정하지 않습니다.

**사이트별 VPN / 일반 통신 규칙**에서 기본 경로를 고르고 `example.com` 형태의 예외를 추가하세요. 도메인과 하위 도메인에 적용되며 더 구체적인 도메인이 우선합니다. 규칙은 암호화해 저장하고 다음 VPN 연결부터 적용합니다. **통신 로그**에서 도메인 행을 선택하면 규칙 입력란에 옮겨집니다. 로그는 연결 시도 메타데이터 최근 300개만 메모리에 보관합니다.

규칙과 통신 로그는 메인 화면의 전용 버튼으로 여는 별도 창에 있습니다. 이 창을 닫아도 VPN 연결은 유지됩니다. 메인 창을 닫으면 연결과 보조 창을 함께 정리합니다.

자동 판단은 VPN/일반 통신 규칙 양쪽의 도메인을 모두 VPN 대상으로 사용합니다. 학습에는 식별된 전체 도메인을 사용하며, 로그의 최근 300개 제한이나 로그 지우기에 영향받지 않습니다. 수동 규칙 64개 제한과 별개로 학습 목록을 연결 동안만 유지하고 종료하면 지웁니다. 10분 뒤에는 새 도메인을 더 학습하지 않습니다. 경로 전환은 새 연결부터 반영되며 기존 연결을 강제로 끊지 않습니다. 학습 목록이 16,384개를 넘거나 전환 파일 저장에 실패하면 연결을 종료합니다. 앱 프록시의 localhost·사설망 직접 연결 예외와 고정 VPN 진단 경로는 유지합니다.

서버 목록은 **남은 사용량 안내 → 일본 → 중국·홍콩 → 싱가포르 → 기타** 순서입니다. 사용량·만료 안내 행은 접속 서버로 선택하지 않습니다. 처음에는 일본의 실제 서버를 VLESS·Hysteria2 순으로 우선 선택하며, 새로고침 시 기존의 유효한 선택을 유지합니다.

서버 이름의 `JP`는 공급자가 붙인 표시입니다. 연결 후 별도의 VPN 전용 HTTPS 진단으로 출구 IP와 판정 국가를 확인하고, 선택한 국가와 다르면 경고합니다. 사이트 규칙에 따른 현재 경로 IP와 VPN 자체의 출구를 구분합니다. IP 국가 판정은 데이터베이스의 추정이며 서버의 물리적 위치나 모든 웹사이트의 국가 판정을 보장하지 않습니다. 앱이 다른 국가의 노드로 자동 전환하지는 않습니다.

사이트의 CDN·다른 로그인 도메인은 각각 지정해야 합니다. ECH·앱 자체 DNS·기존 연결 등으로 도메인을 알 수 없는 통신은 기본 경로를 따릅니다. 사용자가 지정한 일반 통신은 VPN을 거치지 않습니다. 연결 상태 확인용 `connectivitycheck.gstatic.com`은 기본 경로·예외와 관계없이 VPN과 보안 DNS를 사용합니다. 기본이 일반 통신인 경우에도 실제 VPN 출구의 동작을 확인하기 위한 고정 진단 예외입니다.

**앱 프록시**는 Windows 사용자 프록시를 따르는 앱의 HTTP/HTTPS TCP 통신에 적용됩니다. Edge 등에서 이용할 수 있지만 프록시를 무시하는 앱·UDP·게임은 일반 통신을 합니다. 이 모드는 시스템 어댑터·라우트·DNS 설정을 바꾸지 않습니다. localhost·사설망 목적지는 일반 경로를 강제합니다. **TUN**은 IPv4·IPv6 시스템 트래픽과 DNS를 가로채 사이트 규칙을 적용하며 UDP도 지원합니다. 서버의 TCP/UDP 지원·상태·구독 만료에 따라 연결 가능 여부가 달라집니다.

앱 프록시의 로컬 HTTP/SOCKS 포트는 `127.0.0.1`의 임의 포트이며 LAN에 노출하지 않습니다. Windows 프록시 호환성을 위해 인증하지 않으므로 같은 컴퓨터의 다른 사용자도 포트에 접근할 수 있습니다. 강제 종료 후 앱을 다시 열면 앱이 설정한 프록시가 그대로인 경우 이전 값을 복원합니다. 사용자가 다른 프록시로 바꿨다면 그 변경을 유지합니다.

ON/OFF는 이미 맺어진 브라우저 연결을 즉시 바꾸지 않습니다. 프록시 변경 알림을 Windows에 보내지만 브라우저의 반영·연결 재사용 시점에 따라 첫 요청이 이전 경로를 사용하거나 일시적으로 실패할 수 있습니다. 잠시 후 새로고침하고, 계속되면 해당 브라우저 연결을 새로 여세요.

## 보안

- 공급자 프로그램, 플러그인, 스크립트, 루트 인증서를 설치하지 않습니다.
- 공급자 라우팅·DNS·다운로드·파일 설정을 버리고 앱에서 새 설정을 만듭니다. TLS 인증서 검증을 끄는 서버는 거부합니다.
- 코어 SHA-256을 실행 전에 확인합니다. 구독 URL과 인증정보는 `%LOCALAPPDATA%\YaoVPN`에 DPAPI로 암호화해 저장하며 소스나 로그에 기록하지 않습니다.
- 일반 화면과 앱 프록시 코어는 관리자 권한을 사용하지 않습니다. TUN을 선택할 때만 별도 프로세스가 UAC 권한을 요청합니다. 앱을 관리자 권한으로 직접 실행하면 앱 프록시 연결을 거부합니다.
- 공급자 서버의 IP·DNS 응답을 공인 주소로 제한하고 연결 주소를 고정합니다. 공급자 주소로 localhost나 내부망 서비스를 호출하지 않습니다.

통신 중 공격도 고려해야 합니다. 공급자는 HTTP 내용을 변조할 수 있고 VPN 엔진·브라우저 취약점을 악용할 가능성도 있습니다. HTTPS 인증서 검증을 유지하며, 공급자 인증서를 설치하지 않습니다. 관리자 TUN 엔진은 보안 샌드박스가 아니므로 악성 파일 설치의 절대 불가능을 보장할 수는 없습니다. 공격 경로별 대응과 남는 위험은 [보안 점검 문서](SECURITY.md#네트워크-보호-범위)를 확인하세요.

**악성코드 감염 불가능을 보장하지는 않습니다.** 코어·Windows의 취약점이나 직접 실행한 악성 파일은 별도 위험입니다. **영구 킬 스위치는 없습니다.** VPN이 예기치 않게 꺼지면 일반 인터넷으로 돌아갈 수 있습니다. 상세한 범위는 [SECURITY.md](SECURITY.md)를 확인하세요.

## 소스에서 빌드

Windows x64와 .NET 10 SDK가 필요합니다. 외부 NuGet 패키지는 사용하지 않습니다.

```powershell
./scripts/Build.ps1
# SDK가 PATH에 없으면:
./scripts/Build.ps1 -Dotnet 'C:\path\to\dotnet.exe'
```

빌드는 공식 릴리스의 고정 SHA를 검증하고 코어를 준비한 뒤, 보안 회귀 테스트와 자체 런타임을 포함한 실행 폴더를 만듭니다. 원격 PowerShell 스크립트를 받아 실행하지 않습니다.

```powershell
dotnet run --project tests/YaoVpn.Tests -c Release
```

개발용 `--check-private`는 현재 Windows 사용자의 암호화된 `bootstrap.dpapi`를 사용합니다. `--live`는 저장된 구독을 HTTPS로 갱신하고 실제 서버 연결·HTTPS 출구·양방향 사이트 규칙·통신 메타데이터를 로컬 SOCKS 포트에서 확인합니다. 시스템 라우트를 바꾸지 않으므로 이것만으로 관리자 TUN·DNS 누출·IPv6 동작을 검증했다고 간주하지 않습니다. `--browser-proxy`는 사용자 프록시를 일시 적용하는 별도 수동 브라우저 검증 도구이며 Enter 또는 3분 제한 후 복원합니다.

## 제거와 문제 해결

앱에서 OFF 후 창을 닫고 앱 폴더를 삭제하면 됩니다. 자동 시작·Windows 서비스·업체 앱을 등록하지 않습니다. 저장된 구독도 지우려면 앱 종료 후 `%LOCALAPPDATA%\YaoVPN`을 삭제합니다. 인증정보가 들어 있으므로 이 폴더를 공유하지 마세요. 연결 실패 시 다른 서버를 고르거나 구독을 갱신하세요. Windows 보안 기능이나 인증서 검증을 끄지 마세요.
